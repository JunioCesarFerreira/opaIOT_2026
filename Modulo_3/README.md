# Módulo 3

Para o curso OpAIoT cada aluno tem acesso a uma VM conteinerizada na núvem privada LASDPC. Por isso, muitas das práticas deste módulo tem orientações especificas para execução neste ambiente. Em todas as práticas disponibilizamos também um conjunto de scripts docker para que possam executar a atividade prática em outros ambientes, por exemplo, na sua máquina local com Docker.
